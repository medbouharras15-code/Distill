Dépose ici les fichiers PNG/WebP/SVG (transparents) des icônes réalistes de
la barre d'outils Notes, puis renseigne leur chemin dans
`src/lib/notes/toolIconAssets.ts` (ex. `"pen-fineliner": "/tools/pen-fineliner.png"`).
Tant qu'une entrée reste à `null`, l'icône SVG plate existante est utilisée
à la place.
